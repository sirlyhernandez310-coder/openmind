API en línea · v3.0 · Sprints 1, 2 y 3

OpenMind API

Backend REST de la plataforma de psicología y gestión emocional. Autenticación con JWT, roles de paciente, psicólogo y administrador, evaluación emocional, historial y chat de emergencia.

Abrir documentación Swagger Ver ReDoc Panel de administración

Autenticación

Historias OM3-9 Registro de usuario · OM3-10 Inicio de sesión
  • POST
    /api/auth/register/Crea una cuenta de paciente y devuelve la sesión
  • POST
    /api/auth/login/Valida correo y contraseña; responde tokens y rol
  • POST
    /api/auth/refresh/Renueva el token de acceso
  • GET
    /api/auth/me/🔒 JWTPerfil del usuario autenticado
  • POST
    /api/auth/logout/🔒 JWTCierra sesión e invalida el refresh token
  • GET
    /api/auth/users/🔒 AdministradorLista de usuarios (filtro opcional ?role=)
